# Deep-Sea Trenches of the Pacific Ocean: Comparative Submarine Geomorphology

A comprehensive comparative study of the submarine geomorphology of the deep-sea
trenches of the Pacific Ocean, analysing bathymetric data with data-modelling
algorithms implemented in **GMT, QGIS, Python and R**.

This repository holds the full LaTeX source of the monograph together with the
scripts and figures behind it: cartographic mapping and 2D/3D relief modelling
with the Generic Mapping Tools (GMT), spatial analysis in QGIS, and statistical
data modelling, clustering and classification in Python and R.

## Structure

- `deep_sea_trenches_geomorphology.tex` — main LaTeX source (chapters on the Pacific trenches, methodology, results, discussion, conclusions and the programming codes).
- `*.py`, `*.r`, `*.sh` — the Python, R and GMT/AWK scripts used for the analysis and figures.
- `Fig-*.jpg` — the figures.
- `Diagram-Stat-Analysis-R.tex` — supporting R statistical-diagram source.

## Methods

Bathymetric grid processing and 2D/3D relief modelling (GMT); automated
cross-profile extraction and geomorphometric measurement; multivariate statistics,
hierarchical clustering and classification (Python, R); and cartographic
visualisation, applied comparatively across the Pacific deep-sea trenches.
